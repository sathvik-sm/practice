wkt computers understand Machine code -> But very complex for us to understand
Then we have assembly code -> which is also a bit complex to write
Then we have a code like C++ which will later be compiled to Machine code

JavaScript is more easier than C++, but we cant directly run JS on a computer, but we can directly run it on a browser
Running JS inside a browser is possible because of V8 engine, v8 engine is written in C++ by Google. v8 engine compiles JS into Machine code in runtime

JavaScript is confined to browser only, we cant run JS outside the browser because outside the browser we dont have a v8 engine!
This is where NodeJs comes into picture -> NodeJs is also a program written in C++,NodeJs wraps the v8 engine, hence it can run directly on our computer

JavaScript in NodeJs: (code example):
const fs = require("fs");
fs.readFile("a.txt", "utf8", (err, data) => {
  console.log(data);
});

Here:
fs is not part of JavaScript
V8 does not know file systems
Node.js provides the fs module using C/C++ bindings

So Node:

receives your JS
lets V8 execute it
when file access is needed, Node communicates with the OS
returns the result back to JS
What “wraps” specifically means

“Wraps” means:
Node.js surrounds/embeds V8 and provides additional APIs and runtime features around it.

It includes:
event loop
filesystem APIs
networking APIs
timers
process handling
memory management hooks
async I/O via libuv

So Node.js is much bigger than just V8.

Important correction to the statement

This sentence:

“We can't run JS outside the browser because outside browser we don't have V8”

is not fully accurate.

Better version:

“JavaScript needs a runtime environment to execute. Browsers use engines like V8. Node.js embeds V8 and provides a runtime environment outside the browser.”

Because:
Chrome uses V8
Node.js uses V8
Other engines also exist:
SpiderMonkey (Firefox)
JavaScriptCore (Safari)
So JavaScript is not tied only to browsers.

Overall you write code in JavaScript code on a computer, Now NodeJs kind of translates it to C++, which is then compiled down to Machine code

Role of NodeJs in a website is basically to run JavaScript on the back end or server side and then we will be handling requests coming down from a browser,
For example: User might visit our website on a browser, now the browser is going to make a request to the server and the Node Server is going to run some kind of 
JavaScript to give a response to the request and it might communicate with a database or file on the server and then it will send the response back to the browser
That response can be a HTML file with a dynamic data,CSS or some image files.
